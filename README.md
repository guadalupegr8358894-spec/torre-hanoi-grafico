# Torre de Hanói en Python (Versión Gráfica)

Proyecto escolar desarrollado en **Python** que implementa el clásico juego de la **Torre de Hanói** utilizando una interfaz gráfica de usuario (GUI) con la librería **Tkinter**.

## 🚀 Características del Proyecto
* **Interfaz Gráfica Interactiva:** Visualización en tiempo real de las torres, postes y discos mediante un canvas de Tkinter.
* **Modo Manual:** Permite al usuario seleccionar el número de discos (de 1 hasta 64) y moverlos interactivamente haciendo clic entre las torres (A, B y C).
* **Validación de Reglas:** El programa verifica automáticamente que no se coloque un disco más grande sobre uno más pequeño.
* **Contador de Movimientos:** Lleva el registro exacto de cuántos movimientos realizas para completar el desafío.

## 🛠️ Requisitos del Sistema
* Tener instalado **Python 3.x** en tu computadora. *(La librería Tkinter viene incluida por defecto).*
